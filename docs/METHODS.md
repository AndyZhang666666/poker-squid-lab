# 规则、计算与恢复

规则版本：`squid-rules-v1-2026-11-07`。局面版本：`river-last-two-v1`。所有金额以 BB 表示，结算内部使用整数百分之一 BB，避免分别舍入导致收支不平。

## 明确的桌规

阵容一轮内固定，三至九人，默认六人。基础奖励默认 5BB，可设为 0–100BB，最多两位小数。这里的“无限”表示允许重复持标，标记总量仍然有限。

有限模式有 N−1 个标记，每人最多一枚。主池唯一赢家须亮牌才有首次获标资格，重复获标不消耗标记，切池不发标。只剩一人无标时，该人向其余每人支付一份基础奖励。

无限模式有 N＋3 个标记。初始待发两枚；切池使待发＋1，受剩余总量限制；有效获标后待发重置为一枚。首次获标须亮牌，已经持标者重复赢牌不再要求亮牌。未亮牌的首次赢家不获标，待发数量保留。这个边界在本产品中采用明确约定，不将其说成所有场次的通用规则。

一名玩家持有三个及以上标记时，其全部标记按两倍计价。只剩一人无标或供应耗尽时结束；每位无标者独立向每位持标者支付 `标记数 × 倍率 × 基础奖励`。提前结束时未发出的标记不计价、不滚入下一轮。

仅赢边池不具备主池获标资格。沙盘的“仅记录边池结果”是无主池获标的教学事件，不会猜测另一位主池赢家。它不是完整下注或边池裁判。

参考：[Pokr Squid Game](https://help-center.pokr.win/en/battle/guides/squid/)、[BluffKing Squid rules](https://bluffking.ai/en/blog/poker-squid-game-friend-room/)。前者说明主池与亮牌资格，后者提供本版本无限模式的数量、首池、切池及倍率依据。规则页面随每份导出保留版本号。

## 首屏反事实

此前六手赢家是 `UTG, HJ, CO, BTN, HJ, UTG`。有限持标为 `[1,1,1,1,0,0]`；无限持标为 `[3,2,1,1,0,0]`。你是 BB，对手是 SB，是最后两位无标者。

河牌 `2c 3d 7h 9s Jc`，你的牌为 `Th Tc`。对手范围 `QQ:75%, 88:25%` 的两类各有六个合法组合，枚举结果为获胜 25%、落败 75%、平局 0%。这里使用获胜概率计算终局分支，不能将存在平局时的摊牌权益直接代入这两分支公式。

P 为当前底池，已经包含对手下注；C 为跟注成本，P≥C>0。若跟注，直接在河牌摊牌，没有未来下注、抽水或其他玩家争池。

```text
chipEV = p × P − (1−p) × C
sideImprovement = p × (sideWin − sideLose)
callMinusFold = chipEV + sideImprovement
threshold = C / (P + C + sideWin − sideLose)
```

有限模式，赢牌时你收 5BB，输牌或弃牌时支付 25BB。两种终局相差 30BB，25% 的结算改善为 7.50BB。无限模式赢牌时仍收 5BB；输牌时向其他持标者支付 `(3×2+2+1+1+1)×5=55BB`，终局相差 60BB，期望改善为 15BB。

所以默认 P=30、C=15 时，三种 call-minus-fold 为 `−3.75 / +3.75 / +11.25BB`。这是这个明确终局模型的结果，不是任意一手牌的完整策略答案。

## 模拟口径

默认 5,000 轮、种子 20261107、座位相对频率均为 1、切池概率为零。权重允许 1–100，自动归一化。每轮两种模式共享同一串事件；某个模式结束后冻结其结算，事件只继续推进尚未结束的模式。

每手赢家和切池独立抽样。频率是外生假设，不是手牌强度、真实对手拟合或规则造成的行为改变。改变频率与改变规则是不同实验条件。

单轮最多处理 1,000 个事件。未结束的样本单列，不静默丢弃。完成样本的无标比例、分布、平均结算与平均轮长，以各自完成数为分母；存在未完成样本时不能解释为全部样本的无偏预测。

95% Wilson 区间只对完成样本中的无标比例计算，描述有限抽样误差；不覆盖频率、独立性和桌规假设错误。等频、无切池的六人有限模式可以用对称性 `每人末位概率=1/6`、平均轮长 `6×(H₆−1)=8.7` 做独立合理性检查。

## 回放、备份和导入

每个规则状态由配置和事件流重建。回到较早事件后新增事件，会替换之后的分支。改变基础奖励重放当前历史；改变人数新开一轮。结束后的模式不再发标或再次支付。

当前实验与最近 200 次挑战作答使用独立键 `squid-lab-session-v1`，不写入 Poker Lab 的存储。导入校验版本、参数、事件、游标、题目与选项、时间、重复 ID；保存的模拟会按原输入重算并核对。不同设备的挑战作答按 ID 合并，实验设置和回放恢复为导入版本。

最大备份为 4MB。损坏或未知版本的本机记录不会自动覆盖；存储失败时内存体验仍可使用，界面提示导出。主题沿用官网的 `palette` 偏好，减少动效同时遵循系统偏好和本工具的显式开关。
